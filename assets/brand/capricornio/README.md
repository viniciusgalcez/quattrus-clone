# Ativos oficiais da marca Capricórnio

Esta pasta é a fonte canônica das variações do símbolo da Capricórnio fornecidas diretamente pelo usuário em 26 de setembro de 2026.

Os arquivos em `originals/` devem permanecer byte a byte como recebidos. Não sobrescreva, recorte, recolora, redesenhe, vetorize ou remova o símbolo de copyright. Se a aplicação precisar de dimensões, recorte ou formato diferentes, crie um derivado novo em `public/brand/capricornio/`, registre sua origem e preserve o original.

## Regras para o agente programador

- Consulte este catálogo antes de criar ou alterar qualquer uso da marca.
- Use a variante azul-marinho como primeira opção institucional em superfícies claras, salvo orientação específica do operador ou de um manual de marca.
- Em superfícies escuras, escolha uma variante com contraste verificável; não aplique filtros CSS para inverter ou recolorir o arquivo.
- As variações laranja, âmbar, rosa, verde e azul-claro são variações oficiais fornecidas, mas não implicam significado funcional. Não as use automaticamente como status, severidade, departamento ou papel.
- Preserve proporção, área de respiro e contraste. Nunca estique, gire, achate, aplique sombra, glow, gradiente ou contorno.
- A aplicação usa a cópia institucional azul-marinho, preservada byte a byte em `public/brand/capricornio/capricornio-symbol-navy-original.png`. O componente `src/components/CapricornioLogo.tsx` remove apenas o espaço do canvas por enquadramento CSS, sem alterar os pixels do arquivo.
- `public/capricornio-logo.png` é um recorte legado e não deve ser usado em implementações novas.
- `public/login-brand.png` é uma peça da campanha de 80 anos e não substitui estas marcas.
